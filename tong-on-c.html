⚡ Tổng Ôn 8 Bài C Nền Tảng

Đọc kỹ để hồi sinh phản xạ trước khi vào bài kiểm tra 1 tiết A B C D
1
Cấu Trúc Chương Trình C & Hello World
• #include <stdio.h>: Thư viện chuẩn để dùng hàm in/nhập.
• int main(): Điểm khởi đầu bắt buộc của mọi chương trình C. Máy tính luôn bắt đầu chạy từ đây.
• return 0;: Báo cho hệ điều hành biết chương trình chạy kết thúc thành công.
#include <stdio.h> int main() { printf("Hello Phenikaa!\n"); return 0; }
⚠️ Bẫy thường gặp
Quên dấu chấm phẩy ; ở cuối lệnh, hoặc viết sai chữ main (vd: Main).
2
Biến, Kiểu Dữ Liệu & Toán Tử
• int: Số nguyên (%d), tốn 4 bytes.
• float: Số thực (%f), 4 bytes. In 2 số lẻ: %.2f.
• char: 1 ký tự (%c), 1 byte, để trong nháy đơn 'A'.
• Chia nguyên: 5 / 2 = 2 (mất phần thập phân). Muốn ra 2.5 phải viết: 5.0 / 2 hoặc (float)5 / 2.
• Chia dư: 7 % 3 = 1 (chỉ dùng cho số nguyên).
int a = 5, b = 2; float thuong = (float)a / b; // = 2.5 int du = a % b; // = 1
⚠️ Bẫy thường gặp (Toán tử ++ và --)
• x++: Trả về giá trị cũ của x để tính toán trước, rồi mới tăng x.
• ++x: Tăng x lên trước, rồi mới lấy giá trị mới đi tính toán.
3
Nhập / Xuất Chuẩn (printf & scanf)
• printf("%d", x);: Đọc giá trị của x để in ra màn hình (không cần dấu &).
• scanf("%d", &x);: Bắt buộc có & vì cần đưa địa chỉ ô nhớ để CPU ghi số nhập vào ô đó.
int tuoi; printf("Nhap tuoi: "); scanf("%d", &tuoi); // Bắt buộc có &
⚠️ Bẫy thường gặp
scanf("%d", x); quên & sẽ làm sập chương trình (Crash / Segfault). Riêng mảng ký tự chuỗi thì không cần &.
4
Cấu Trúc Rẽ Nhánh (if - else & switch - case)
• Toán tử so sánh: == (bằng), != (khác), >, <, >=, <=.
• Toán tử logic: && (VÀ), || (HOẶC), ! (PHỦ ĐỊNH).
• switch(biến): Dùng khi so sánh 1 biến với nhiều hằng số nguyên/ký tự.
if (diem >= 8.5) { printf("Gioi\n"); } else if (diem >= 7.0) { printf("Kha\n"); } else { printf("Trung binh\n"); }
⚠️ 2 Bẫy trắc nghiệm kinh điển
1. Viết if (x = 5) thay vì if (x == 5). Lệnh gán x = 5 khiến điều kiện luôn luôn ĐÚNG (khác 0)!
2. Trong switch - case, quên lệnh break; sẽ khiến code chạy tuồn tuột xuống các case bên dưới (Fall-through).
5
Vòng Lặp (for, while, do - while)
• for(khởi tạo; điều kiện; bước nhảy): Dùng khi biết trước số lần lặp.
• while(điều kiện): Kiểm tra điều kiện trước, đúng mới làm.
• do { ... } while(điều kiện);: Làm trước ít nhất 1 lần rồi mới kiểm tra điều kiện.
• break;: Thoát hẳn khỏi vòng lặp ngay lập tức.
• continue;: Bỏ qua các lệnh còn lại ở lượt hiện tại, nhảy ngay sang lượt lặp kế tiếp.
int tong = 0; for (int i = 1; i <= 5; i++) { tong += i; // 1 + 2 + 3 + 4 + 5 = 15 }
⚠️ Bẫy thường gặp
Viết thừa dấu chấm phẩy: for (int i=0; i<5; i++); → vòng lặp rỗng chạy một mình, ngoặc nhọn bên dưới chỉ chạy 1 lần!
6
Hàm (Function)
• Chia nhỏ chương trình thành các khối chức năng tái sử dụng.
• void: Hàm không trả về giá trị (chỉ in hoặc làm việc gì đó).
• return: Trả giá trị về cho nơi gọi hàm và kết thúc hàm ngay lập tức.
• Biến cục bộ (Local Variable): Biến khai báo trong hàm nào thì chỉ sống trong hàm đó, hàm kết thúc là biến biến mất.
int tinhTong(int a, int b) { return a + b; } int main() { int s = tinhTong(3, 7); // s = 10 }
⚠️ Bẫy thường gặp (Tham trị - Pass by Value)
Khi truyền biến thường vào hàm (vd: tang(x)), hàm chỉ nhận được bản sao. Mọi thay đổi trong hàm không ảnh hưởng biến ở main!
7
Mảng 1 Chiều (Array)
• Mảng là tập hợp nhiều biến cùng kiểu nằm liền kề nhau trong bộ nhớ RAM.
• Khai báo: int a[5]; → có 5 phần tử: a[0], a[1], a[2], a[3], a[4].
• Chỉ số bắt đầu từ 0 đến n - 1.
int a[4] = {10, 20, 30, 40}; for (int i = 0; i < 4; i++) { printf("%d ", a[i]); }
⚠️ Bẫy truy cập ngoài mảng (Out of Bounds)
Mảng int a[5]; chỉ có đến a[4]. Nếu bạn gọi a[5] là đang đọc trúng vùng nhớ rác nguy hiểm!
8
Chuỗi Ký Tự (String)
• Chuỗi trong C thực chất là mảng ký tự kết thúc bằng ký tự đặc biệt '\0' (Null terminator, mã ASCII = 0).
• Khai báo: char s[20] = "Phenikaa";
• In chuỗi: printf("%s", s);
• Nhập chuỗi có dấu cách: Dùng fgets(s, sizeof(s), stdin); (tránh dùng scanf("%s") vì dừng khi gặp dấu cách).
• Thư viện #include <string.h>: strlen(s) đếm số ký tự (không tính ký tự '\0').
#include <string.h> char ten[20] = "AI K20"; printf("Do dai: %zu\n", strlen(ten)); // In ra: 6
⚠️ Bẫy kích thước chuỗi
Muốn lưu chuỗi có 5 chữ cái (vd: "Hello"), mảng phải có kích thước tối thiểu là 6 ô nhớ để chừa 1 ô cho ký tự '\0'!
